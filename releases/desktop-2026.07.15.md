# Matrix Co Desktop 2026.07.15

Apple Silicon macOS desktop build from Matrix Co source commit `5b9a7b374bc9f89e4e27e8425e0f3f4f62ded007`.

This update polishes the room composer and native window layout, adds collapsible room navigation, persists room reading position, stabilizes history loading and message positioning, compacts streamed command output, and keeps plan dialogs above active work state.

## Install

1. Download `Matrix.Co.dmg`.
2. Open the DMG and copy Matrix Co to Applications.
3. This build is ad-hoc signed but not Developer ID signed or notarized. On first launch, right-click Matrix Co and choose **Open** if macOS blocks the app.

Third-party agent CLIs are not bundled. Install and authenticate the Codex, Claude Code, Cursor, Kimi, or ZCode CLI separately for the adapters you plan to use.
